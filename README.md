# เดโม่ tooktale

เดโม่แบบกดเล่นได้ 4 แอป ทุกแอปส่งข้อมูลถึงกันแบบเรียลไทม์ ใช้ข้อมูลตัวอย่างทั้งหมด ไม่ใช้กับแขกจริง

| แอป | ใครใช้ | พอร์ต | โฟลเดอร์ |
|---|---|---|---|
| Hub (หน้า QR + บทพรีเซ้น) | คนพรีเซ้น | 4100 | [hub/](hub/) |
| **tooktale** | แขก | 4101 | [tooktale/](tooktale/) |
| **tooktale partner** | ร้านเช่า | 4102 | [tooktale-partner/](tooktale-partner/) |
| **tooktale runner** | คนเดินรถ | 4103 | [tooktale-runner/](tooktale-runner/) |
| **nakola tooktale** | ทีม nakola | 4104 | [nakola-tooktale/](nakola-tooktale/) |
| mock API + ฐานข้อมูลไฟล์ JSON | ทุกแอป | 4105 | [api/](api/) |

โค้ดที่ใช้ร่วมกัน (ธีม รูปรถ แผนที่ หลักฐาน แชท) อยู่ใน [shared/](shared/)

## เปิดเดโม่

ต้องมี Docker Desktop เปิดอยู่ ไม่ต้องลง Node

1. ดับเบิลคลิก `start.cmd` (หรือรัน `.\start.ps1`)
2. หน้า Hub เปิดเอง มี QR ของทุกแอป
3. มือถือต่อ Wi-Fi วงเดียวกับเครื่องนี้ แล้วสแกน QR

ปิดด้วย `stop.cmd` ข้อมูลยังอยู่ ถ้าแก้โค้ดแล้วรัน `.\start.ps1 -Build`

## ก่อนพรีเซ้นทุกครั้ง

- **รัน `start.cmd` ใหม่ทุกครั้งที่ย้าย Wi-Fi** IP ของเครื่องเปลี่ยนตามวง ถ้าไม่รันใหม่ QR จะชี้ไป IP เก่าแล้วมือถือเปิดไม่ได้ (เคยเจอแล้ว 2026-11-08: 192.168.37.252 → 192.168.1.102)
- **กด "ล้างเดโม่" ในหน้า Hub** งาน "วันนี้" อิงจากวันที่กดล้าง ถ้าไม่ล้างจะเห็นงานเก่าค้าง · คำขอจองตัวอย่างจะยืนยันเองใน ~10 นาที ถ้าจะโชว์กด "รับจอง" ให้ล้างก่อนเริ่มไม่นาน
- **เปลี่ยนชื่อร้านเป็นของร้านที่จะไปคุย:** partner → เพิ่มเติม → ข้อมูลร้าน และแก้รถ ราคา กติกาให้ตรงร้านนั้น
- **ต้อง build ตอนมีเน็ตครั้งแรกเท่านั้น** หลังจากนั้นทุกอย่างทำงานโดยไม่มีอินเทอร์เน็ต ขอแค่มี Wi-Fi วงเดียวกัน

## ถ้ามือถือเปิดไม่ได้

1. เช็คว่ามือถือกับเครื่องอยู่ Wi-Fi วงเดียวกัน
2. **Wi-Fi โรงแรมมักกันเครื่องคุยกันเอง** ถ้าเจอแบบนี้ เปิด hotspot จากมือถือ ให้คอมกับมือถือเครื่องอื่นต่อ hotspot นั้น แล้วรัน `start.cmd` ใหม่ (IP เปลี่ยน)
3. ถ้ายังไม่ได้ เปิดทุกแอปบนคอมผ่านปุ่ม "เปิดทุกแอปบนจอเดียว" ในหน้า Hub แล้วพรีเซ้นบนจอเดียว

## บทพรีเซ้น

หน้า Hub มี 4 เส้นทางให้กดตาม (A จองรับที่ร้าน · B ส่งถึงจุด · C walk-in · D แชทก่อนจอง)
ตรงกับ [feature-map ข้อ 4](https://github.com/nakola-app/nakola-plan/blob/main/features/feature-map-2026-11-03.md)

ปุ่มช่วยเล่าเรื่องที่มีเฉพาะในเดโม่:
- **กรอกข้อมูลตัวอย่าง** ตอนจอง
- **ถ่ายให้ครบ 4 ด้าน** ใส่รูปตัวอย่างของรถคันนั้น
- **จำลองรอยใหม่** ใส่รอยลงรูป เพื่อโชว์การเทียบรูปและการบอกว่ารอยเกิดช่วงไหน

## ของจำลอง

| เรื่อง | ในเดโม่ | ของจริง |
|---|---|---|
| Login LINE | กดแล้วเลือกบัญชีตัวอย่าง | LINE จริง |
| แจ้งเตือน | ป้ายเด้งบนจอ แยกเป็น LINE/อีเมล | ส่งจริง |
| รูปถ่าย | รูปวาดตามสีรถ | กล้องมือถือ |
| เงิน | ไม่มีการจ่ายในระบบ (H4) | ยังไม่เคาะ |
| แผนที่ | วาดเอง ไม่ตรงมาตราส่วน | แผนที่จริง |
| ชื่อร้าน แขก ราคา จุดรับส่ง จุดเที่ยว | สมมุติทั้งหมด | ของจริงจากสนาม |

## ดีไซน์ฝั่งลูกค้า

แอป tooktale ใช้โทนน้ำเงิน-ขาว หัวข้อ serif เอียง ขอบโค้ง และการ์ดลอย ตามภาพอ้างอิงที่ founder ให้มา 2026-11-06 ใช้ได้ทั้งจอคอมและมือถือ
แอปอีก 3 ตัวยังใช้ธีมเดิม

- **ฉากทะเลเป็นภาพวาด SVG** ไม่ใช่รูปถ่าย ถ้ามีรูปจริงของเกาะหรือร้าน เปลี่ยนที่ [tooktale/src/Scene.jsx](tooktale/src/Scene.jsx)
- **ตัดของที่ไม่มีข้อมูลจริงออก:** คะแนนดาว จำนวนลูกค้า โปรลดราคา (รีวิวอยู่ P1 และเดโม่ไม่มีเรื่องเงิน)

## ที่ทำต่างจาก feature-map

- **walk-in** เริ่มที่ "ยืนยันแล้ว" แล้วเป็น "กำลังเช่า" เมื่อแขกกดยอมรับใบตกลง เพราะข้อ 3 กำหนดว่าเข้า "กำลังเช่า" ได้ทางเดียว (ข้อความ "walk-in เริ่มที่กำลังเช่าทันที" ในข้อเดียวกันขัดกันเอง)
- **ภาษาในแชท** ใช้ปุ่มภาษาไทยที่ส่งเป็นภาษาของแขก (ไม่มีภาษานั้น = อังกฤษ) เป็นทางแก้ชั่วคราวของ [team-decisions 3.2](https://github.com/nakola-app/nakola-plan/blob/main/decisions/team-decisions-2026-11-03.md) · ข้อความที่ร้านพิมพ์เองไม่แปล
- **ส่งรถถึงจุดปิดอยู่ (2026-11-09):** รอ payment gateway · แขกรับ-คืนที่ร้านอย่างเดียว · แอปคนเดินรถขึ้นว่าปิดชั่วคราว · **ถ้าจะโชว์บท B ให้เปิดสวิตช์ที่ Admin → คนเดินรถ ก่อน** (กดล้างเดโม่ = กลับเป็นปิด) · [decisions/runner-paused-2026-11-09.md](https://github.com/nakola-app/nakola-plan/blob/main/decisions/runner-paused-2026-11-09.md)
- **ค่าธรรมเนียม + ใบแจ้งยอด (2026-11-09):** แขกเห็นค่าธรรมเนียม 10% (ตัวอย่าง) รวมในยอดจ่ายร้าน · บังโต้ (เจ้าของ) → เพิ่มเติม → ค่าธรรมเนียม tooktale → ใบแจ้งยอดเดือนก่อน "รอโอน" → แจ้งโอน · Admin → เรียกเก็บ → ยืนยันได้รับเงิน · ฟ้า (แอดมินร้าน) ไม่เห็น · [decisions/guest-fee-billing-2026-11-09.md](https://github.com/nakola-app/nakola-plan/blob/main/decisions/guest-fee-billing-2026-11-09.md)
- **ทีมงานร้าน (2026-11-09):** ล็อกอินร้านเลือก "คน" · บ้านทะเลไบค์มี บังโต้ = เจ้าของ (เห็นตัวเลขร้าน · เชิญ/ลบแอดมิน) · ฟ้า = แอดมิน (ไม่เห็นตัวเลขร้าน) · ลองเชิญแอดมินจากเมนู เพิ่มเติม → ทีมงานร้าน · [decisions/shop-team-roles-2026-11-09.md](https://github.com/nakola-app/nakola-plan/blob/main/decisions/shop-team-roles-2026-11-09.md)
- **รูปแขกตอนกดยอมรับบนเครื่องร้าน (2026-11-09):** กล้องไหนก็ได้ · เว็บแคม/กล้องสดเปิดได้เฉพาะ https หรือ localhost → ในเดโม่ถ้าจะโชว์เว็บแคม เปิดหน้าร้านที่ `http://localhost:4102` บนคอมที่รันเดโม่ · มือถือผ่าน IP ใช้ปุ่มถ่ายรูปของเครื่อง
- **ยืนยันอัตโนมัติ (2026-11-09):** ร้านไม่ตอบใน 15 นาที = ยืนยันเอง · ร้านเปลี่ยนรถ (ราคาขึ้นไม่ได้) หรือยกเลิกได้ก่อนส่งมอบ · ปุ่ม "เดโม่: ข้ามเวลารอ" ใช้โชว์ · ⚠️ คำขอตัวอย่าง 2 ใบยืนยันเองราว 8 และ 11 นาทีหลังล้างเดโม่ · ดูบท E ในหน้า hub · [decisions/auto-confirm-2026-11-09.md](https://github.com/nakola-app/nakola-plan/blob/main/decisions/auto-confirm-2026-11-09.md)
- **ภาษา (2026-11-09):** แขกมี อังกฤษ/ไทย/จีน จับจากภาษาเครื่อง · ใบตกลงร้านต้องมีอังกฤษ ภาษาอื่นร้านเลือกเปิด · ร้านบ้านทะเลไบค์เปิดจีนไว้ ร้านยาวบรีซไม่เปิด (โชว์ได้ทั้ง 2 แบบ) · ลองเปลี่ยนภาษามือถือเป็นจีนแล้วเปิดลิงก์แขก · รายละเอียด [decisions/languages-2026-11-09.md](https://github.com/nakola-app/nakola-plan/blob/main/decisions/languages-2026-11-09.md)
- **เพิ่ม** ระดับน้ำมันในทุกชุดรูป และการตั้งค่าร้านผ่านหน้า partner (เพื่อเปลี่ยนชื่อร้านก่อนพรีเซ้น)
